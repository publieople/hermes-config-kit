# 中国市场 AI 定价数据 & 制度来源（2026-08 调研）

## AI 智能体市场分层（来源：阿里云开发者社区 2026-03、实在智能 2026-05、数商云 2026）

| 层级 | 价格 | 内容 | 周期 |
|------|------|------|------|
| 基础型 | 3-8 万 | 单任务、Prompt+轻 RAG（<100 份文档）、简单 API 联调 | 2-4 周 |
| 进阶型/行业级 | 15-40 万 | GraphRAG、多 Agent 协同、定制 UI/小程序 | 2-3 个月 |
| 企业级 | 50-150 万+ | 私有化部署、模型微调、ERP/CRM/数字孪生集成 | 4-6 个月 |
| 行业级大项目 | 80-300 万 | 全链路业务自动化（制造/金融/能源） | - |
| 年框战略合作 | 300-1000 万/年 | 专属模型训练、多 Agent 平台、7×24 | - |

其他数据点：
- 按用户规模：500 人以下内部使用 50-80 万/年；500-5000 人 80-150 万/年
- 行业一口价：财务/合同审核 Agent 100-200 万；代码开发测试 Agent 80-150 万
- API 调用费：DeepSeek/豆包/文心 0.001-0.05 元/千 token；活跃用户约 1-2 元/天
- 年运维费：开发费 15%-25%

## RPA/数字员工（来源：达观数据、艾瑞 2023、实在智能）

- 软件许可：基础版 1.5-3.5 万/年，企业版 7-15 万/年
- 流程开发实施：7-35 万（复杂度越高越贵）
- 年度维护：3.5-15 万
- AI 模块扩展（OCR/NLP）：2-7 万
- 每增加一个系统接口：+1-3 万
- 外包人天：约 1500 元/人/天（深圳行情）

## 高校横向课题制度（来源：各校管理办法原文）

| 学校 | 关键条款 |
|------|---------|
| 上海交大医学院 | 合同金额 ≥10 万的技术开发合同，通过认定后正式立项横向课题 |
| 华南理工 | 管理费：300 万及以下按 5%（技术开发/服务/转让）、4%（技术咨询）；**软件开发类劳务费可放宽到 80%** |
| 浙江师大 | 管理费：100 万及以下 6%，逐级递减至 1% |
| 南京大学 | 合同标的额 ≥100 万须学校法律顾问审核 |
| 通用 | 技术开发/转让合同经技术认定登记可免征增值税；成果知识产权通常归委托方，研发方保留署名和后续使用权 |

横向项目类型：技术开发、技术服务、技术咨询、技术转让四种合同。

## 报价甜点区间推导（学校实验室场景）

- 10 万 = 横向课题立项线（交大规则），低于此连科研业绩都不算
- 12-15 万 = 成本结构：学生劳务 60% + 导师指导 15% + 设备/API 10% + 管理费 6% + 结余 9%
- 18 万 = 上限（开源框架 + 集团内部项目，再高被质疑）
- 付款节奏：签订 50% + 试运转验收 50%

## docx 方案生成 pitfall（本次踩坑）

- docx-js 跨页表格表头重复：`TableRow` 用 `tableHeader: true`（不是 `header: true`，后者在 9.7.1 静默失效），数据行加 `cantSplit: true`
- 验证：`unzip -p out.docx word/document.xml | grep -c tblHeader`
- 批量改写生成脚本后必须 `node --check gen.js` 再执行（正则误伤 PageBreak 行 `] }),` 尾部）
