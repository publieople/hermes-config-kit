## 文案设计说明

| 设计点 | 理由 |
|--------|------|
| "装不上不收费" 放第一句 | 直接打消买家最大顾虑 |
| 价格明标 199/499/999 | 无价商品闲鱼曝光低 |
| Agent 按熟悉度排序 | Hermes 最熟放第一，不是按知名度排 |
| "含2轮修改，超出另议" | 替代危险的"不限次" |
| "拍前先聊" | 防止没确认需求就下单的纠纷 |
| 信任段写真实经历 | "我跑过" > "我会"，一句真话胜过十句自夸 |
| 结尾三行（时间/准备/禁止） | 所有必要说明一次性交代，减少无效咨询 |
